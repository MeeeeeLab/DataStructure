# 递归字符串双端检查器

> 项目ID：`daily-2026-11-26` · Java工作日小练习约25–35分钟 · 不表示已经完成。

## 目标

用递减索引和双端收缩实现字符串反转与回文判断。

## 步骤

1. 明确null与空串的不同契约。
2. 从length()-1开始递归追加字符，index<0终止。
3. 比较左右字符，left>=right终止。
4. 验收普通、空串、单字符、中文、非回文和null。

保存为`RecursiveStringTools.java`并运行：

```bash
java -ea RecursiveStringTools.java
```

预期：`recursive-string checks: OK`。
