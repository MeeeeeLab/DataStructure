# 排队叫号系统

> 周末项目 ID：`weekend-2026-11-21` · Java 项目约 55–65 分钟 · 本页提供可独立完成的周日完整材料，不表示 11 月 21 日或今日已经完成。

## 目标

用同一接口实现循环数组队列和链表队列，并完成队列章节验收。

## 今日任务

1. 定义 `TicketQueue` 公共契约。
2. 实现固定容量循环数组队列。
3. 实现维护 head/tail 的链表队列。
4. 用共享测试验收空、单元素、复用与FIFO。
5. 单独验收满容量、回绕和非法容量。
6. 说明两种实现的 O(1) 操作与空间取舍。

## 运行

保存为 `TicketServiceSystem.java`，执行：

```bash
java -ea TicketServiceSystem.java
```
