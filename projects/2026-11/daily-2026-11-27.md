# 递归数组区间求和器

> 项目ID：`daily-2026-11-27` · Java工作日小练习约25–35分钟 · 不表示已经完成。

## 目标

用半开区间和递增索引递归求和，并验证数组边界契约。

## 步骤

1. 检查`0 <= from <= to <= length`。
2. 用`from == to`表示空区间并返回0。
3. 返回当前元素加剩余区间结果。
4. 验收空数组、负数、null和错误端点。

保存为`RecursiveRangeSum.java`并运行：

```bash
java -ea RecursiveRangeSum.java
```

预期：`recursive-range-sum checks: OK`。
