# 循环排队队列

> Java 工作日短练习 20–25 分钟 · 不表示已经完成。

## 目标

用head、size和取模实现不搬移元素的固定容量FIFO队列。

## 分步任务

1. **定义状态**：用head和size区分队头、空与满。（不额外保存tail。）
2. **取模回绕**：计算tail并让head循环后移。（使用%data.length。）
3. **边界自检**：覆盖回绕、满空和容量1。（先删除A再加入D。）

## 运行

```bash
java -ea CircularServiceQueue.java
```

## 自测

- 回绕FIFO：capacity=3; A,B,C; dequeue A; enqueue D → `circular-queue checks: OK`
- 容量边界：empty, blank, full, capacity=1, capacity=0 → `circular-queue checks: OK`

<details><summary>参考实现</summary>

```java
import java.util.NoSuchElementException;

public class CircularServiceQueue {
    private final String[] data;
    private int head;
    private int size;

    public CircularServiceQueue(int capacity) {
        if (capacity <= 0) {
            throw new IllegalArgumentException("capacity must be positive");
        }
        data = new String[capacity];
    }

    public void enqueue(String ticket) {
        if (ticket == null || ticket.isBlank()) {
            throw new IllegalArgumentException("ticket cannot be blank");
        }
        if (size == data.length) {
            throw new IllegalStateException("queue is full");
        }
        int tail = (head + size) % data.length;
        data[tail] = ticket;
        size++;
    }

    public String dequeue() {
        if (size == 0) {
            throw new NoSuchElementException("queue is empty");
        }
        String ticket = data[head];
        data[head] = null;
        head = (head + 1) % data.length;
        size--;
        return ticket;
    }

    public String peek() {
        if (size == 0) {
            throw new NoSuchElementException("queue is empty");
        }
        return data[head];
    }

    public int size() {
        return size;
    }

    private static void expect(Class<? extends Throwable> type, Runnable action) {
        try {
            action.run();
        } catch (Throwable error) {
            if (type.isInstance(error)) return;
            throw error;
        }
        throw new AssertionError("expected " + type.getSimpleName());
    }

    public static void main(String[] args) {
        CircularServiceQueue queue = new CircularServiceQueue(3);
        expect(NoSuchElementException.class, queue::dequeue);
        expect(IllegalArgumentException.class, () -> queue.enqueue(" "));
        queue.enqueue("A");
        queue.enqueue("B");
        queue.enqueue("C");
        expect(IllegalStateException.class, () -> queue.enqueue("D"));
        assert queue.dequeue().equals("A");
        queue.enqueue("D");
        assert queue.peek().equals("B");
        assert queue.dequeue().equals("B");
        assert queue.dequeue().equals("C");
        assert queue.dequeue().equals("D");
        assert queue.size() == 0;

        CircularServiceQueue one = new CircularServiceQueue(1);
        one.enqueue("X");
        assert one.dequeue().equals("X");
        one.enqueue("Y");
        assert one.dequeue().equals("Y");
        expect(IllegalArgumentException.class, () -> new CircularServiceQueue(0));
        System.out.println("circular-queue checks: OK");
    }
}
```

</details>

## 复盘

- 为什么tail可以由head和size计算？
- 队列占用从head起连续size个循环槽，下一空槽就是(head+size)%capacity。
