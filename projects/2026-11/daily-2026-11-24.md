# 递归阶乘调用追踪器

> 项目ID：`daily-2026-11-24` · Java工作日小练习约25–35分钟 · 不表示已经完成。

## 目标

用阶乘追踪调用深入、终止与逆序返回，并控制long边界。

## 步骤

1. 限制输入为0到20。
2. 用n==0返回1作为终止条件。
3. 写`n * factorial(n-1)`。
4. 精确记录factorial(4)的调用和返回。
5. 验收0、1、5、20、负数和21。

保存为`RecursiveFactorial.java`并运行：

```bash
java -ea RecursiveFactorial.java
```

预期：`recursive-factorial checks: OK`。
