# 括号匹配短练习

> Java 工作日短练习 20–25 分钟；发布内容不表示已经完成。

## 目标

用Deque栈验证三类括号的嵌套顺序。

## 先修

- 栈LIFO
- Java类
- 异常与边界

## 分步任务

1. **扫描字符**：左括号push。（提示：普通字符忽略。）
2. **匹配右括号**：先判空再pop比较。（提示：最近左括号优先。）
3. **测试边界**：覆盖空串和错误嵌套。（提示：结束还要判空。）

## 本地运行

```bash
java BracketMatcher.java
```

## 自测

- 正确嵌套：[()]{}{[()()]()} → `bracket checks: OK`
- 错误与空串：[(]), ((), ), empty → `bracket checks: OK`

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class BracketMatcher {
    static boolean isBalanced(String text) {
        Deque<Character> openings = new ArrayDeque<>();
        for (char ch : text.toCharArray()) {
            if (ch == '(' || ch == '[' || ch == '{') {
                openings.push(ch);
            } else if (ch == ')' || ch == ']' || ch == '}') {
                if (openings.isEmpty() || !matches(openings.pop(), ch)) return false;
            }
        }
        return openings.isEmpty();
    }

    private static boolean matches(char left, char right) {
        return left == '(' && right == ')' || left == '[' && right == ']'
                || left == '{' && right == '}';
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        check(isBalanced("[()]{}{[()()]()}"), "nested");
        check(isBalanced(""), "empty");
        check(isBalanced("a+(b*c)"), "ordinary characters");
        check(!isBalanced("[(])"), "crossed");
        check(!isBalanced("(()"), "leftover opening");
        check(!isBalanced(")"), "early closing");
        System.out.println("bracket checks: OK");
    }
}
```
