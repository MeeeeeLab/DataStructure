# 递归求和调用追踪器

> 项目 ID：`daily-2026-11-23` · Java 工作日小练习约25–35分钟 · 不表示已经完成。

## 目标

用终止条件、递减参数和精确轨迹理解递归调用与返回。

## 步骤

1. 拒绝负数输入。
2. 为n=0写直接返回的终止条件。
3. 用`n + sumTo(n - 1)`缩小问题。
4. 记录n=3的进入与返回顺序。
5. 验收0、1、4和负数边界。

保存为`RecursionBasics.java`并运行：

```bash
java -ea RecursionBasics.java
```
