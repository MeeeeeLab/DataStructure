## 1. 为什么让链表头当栈顶

若 `top` 指向单链表头：

- push：新节点的 next 指向旧 top，再让 top 指向新节点。
- pop：保存 top.value，再让 top 指向 top.next。
- peek：直接读取 top.value。

三个操作都只处理头部，不需要遍历，因此都是 O(1)。每个元素额外保存一个 next 引用，总空间 O(n)。

## 2. 可运行示例

```java
import java.util.NoSuchElementException;

public class LinkedIntStack {
    private static class Node {
        int value;
        Node next;

        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    private Node top;
    private int size;

    void push(int value) {
        top = new Node(value, top);
        size++;
    }

    int pop() {
        if (top == null) throw new NoSuchElementException("stack is empty");
        int value = top.value;
        top = top.next;
        size--;
        return value;
    }

    int peek() {
        if (top == null) throw new NoSuchElementException("stack is empty");
        return top.value;
    }

    int size() {
        return size;
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        LinkedIntStack stack = new LinkedIntStack();
        check(stack.size() == 0, "initial size");
        stack.push(10);
        stack.push(20);
        stack.push(30);
        check(stack.peek() == 30 && stack.size() == 3, "peek");
        check(stack.pop() == 30 && stack.pop() == 20 && stack.pop() == 10, "LIFO");
        check(stack.size() == 0, "empty size");
        try {
            stack.peek();
            throw new AssertionError("empty peek accepted");
        } catch (NoSuchElementException expected) {
            System.out.println("linked-stack checks: OK");
        }
    }
}
```

运行 `java LinkedIntStack.java`，已核对空栈、三次入栈、peek、LIFO 出栈、size 恢复为 0 与空栈异常：

```text
linked-stack checks: OK
```

## 3. 数组栈与链表栈

| 比较 | 固定数组栈 | 链表栈 |
| --- | --- | --- |
| 栈顶位置 | data[size-1] | top 节点 |
| push/pop | O(1) | O(1) |
| 容量 | 预先固定 | 按节点增长 |
| 额外空间 | 可能有空槽 | 每节点一个 next |
| 主要边界 | 满栈与空栈 | 空栈 |

## 4. 易错点和练习

- push 后忘记更新 top。
- pop 先改 top 再读取值，导致旧值丢失。
- size 与节点数量不同步。
- 空栈直接访问 top.value。

练习：
1. 画出 push(10)、push(20)、push(30) 后的 next 链。
2. 手动执行一次 pop，标出新 top。
