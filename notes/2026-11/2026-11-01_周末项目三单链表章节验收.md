## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 空链展示 | 空字符串 |
| 首次加入 | 新节点成为 head |
| 重复学号 | 返回 false，链表不变 |
| 查找不存在 | 返回 null |
| 删除 head | head 前移 |
| 删除最后单节点 | head 变 null |
| 空链删除 | 返回 false |

## 复杂度说明

- 首次加入空链：O(1)。
- 无 tail 的尾插：O(n)。
- 查找和按值删除：最坏 O(n)。
- 展示：O(n)，输出字符串占 O(n)。
- 连续进行查找再删除：O(n)+O(n)=O(n)，不是 O(n²)。

## D+7 主动回忆

数组有效区间需要显式维护 `size`，删除常伴随移动；链表通过 `next` 连接节点，删除不移动后续元素，但仍可能先花 O(n) 查找目标。这是两种结构的核心差异之一。

## 典型失误

- 把“会读参考答案”当作“能独立实现”。
- 只测两个普通节点，不测空、单节点和未命中。
- 误以为链表按值删除总是 O(1)。
- 为减少特殊情况提前引入双链表或哨兵，超出本周验收范围。
