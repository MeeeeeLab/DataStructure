## 1. 数组怎样表示栈

用 `int[] data` 保存元素，用 `size` 同时表示元素数量和下一个可写位置：

- 入栈：`data[size++] = value`
- 栈顶：`data[size - 1]`
- 出栈：`data[--size]`

空栈条件是 `size == 0`，满栈条件是 `size == data.length`。先检查边界，再访问数组。

## 2. 可运行示例

```java
import java.util.NoSuchElementException;

public class ArrayIntStack {
    private final int[] data;
    private int size;

    ArrayIntStack(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException("capacity must be positive");
        data = new int[capacity];
    }

    void push(int value) {
        if (size == data.length) throw new IllegalStateException("stack is full");
        data[size++] = value;
    }

    int pop() {
        if (size == 0) throw new NoSuchElementException("stack is empty");
        return data[--size];
    }

    int peek() {
        if (size == 0) throw new NoSuchElementException("stack is empty");
        return data[size - 1];
    }

    int size() {
        return size;
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        ArrayIntStack stack = new ArrayIntStack(3);
        stack.push(10);
        stack.push(20);
        stack.push(30);
        check(stack.peek() == 30 && stack.size() == 3, "peek");
        try {
            stack.push(40);
            throw new AssertionError("overflow accepted");
        } catch (IllegalStateException expected) {
            // expected
        }
        check(stack.pop() == 30 && stack.pop() == 20 && stack.pop() == 10, "LIFO");
        try {
            stack.pop();
            throw new AssertionError("underflow accepted");
        } catch (NoSuchElementException expected) {
            System.out.println("array-stack checks: OK");
        }
    }
}
```

运行 `java ArrayIntStack.java`，已核对三次入栈、peek 不删除、LIFO 出栈、满栈溢出与空栈下溢：

```text
array-stack checks: OK
```

## 3. 复杂度与边界

固定容量实现中 `push`、`pop`、`peek` 都是 O(1)，空间为 O(capacity)。缺点是容量在构造时固定；今天明确抛异常，不静默覆盖旧元素。

| 情况 | 行为 |
| --- | --- |
| capacity <= 0 | 构造失败 |
| size == data.length 后 push | 抛 IllegalStateException |
| size == 0 后 pop/peek | 抛 NoSuchElementException |
| peek | 不改变 size |
| pop | 先减 size，再读原栈顶 |
