## 核心原理

撤销遵循“最后一次修改最先撤销”，正是 LIFO。每次成功修改前，把旧文本压入栈；执行 `undo` 时弹出最近快照并恢复。空操作不改变文本，因此不应产生虚假历史。

## Java 示例

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class UndoActionSimulator {
    private final StringBuilder text = new StringBuilder();
    private final Deque<String> previousStates = new ArrayDeque<>();

    void type(String value) {
        if (value == null || value.isEmpty()) return;
        previousStates.push(text.toString());
        text.append(value);
    }

    boolean deleteLast() {
        if (text.isEmpty()) return false;
        previousStates.push(text.toString());
        text.deleteCharAt(text.length() - 1);
        return true;
    }

    boolean undo() {
        if (previousStates.isEmpty()) return false;
        text.setLength(0);
        text.append(previousStates.pop());
        return true;
    }

    String text() {
        return text.toString();
    }

    int undoCount() {
        return previousStates.size();
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        UndoActionSimulator editor = new UndoActionSimulator();
        check(!editor.undo() && !editor.deleteLast(), "empty operations");
        editor.type("A");
        editor.type("B");
        check(editor.text().equals("AB") && editor.undoCount() == 2, "type");
        check(editor.deleteLast() && editor.text().equals("A"), "delete");
        check(editor.undo() && editor.text().equals("AB"), "undo delete");
        check(editor.undo() && editor.text().equals("A"), "undo type B");
        check(editor.undo() && editor.text().isEmpty(), "undo type A");
        check(!editor.undo(), "history exhausted");
        System.out.println("undo-simulator Saturday checks: OK");
    }
}
```

运行：

```bash
java UndoActionSimulator.java
```

输出：

```text
undo-simulator Saturday checks: OK
```

## 复杂度

设当前文本长度为 n。快照使用 `toString()` 复制全文，因此一次成功修改或撤销最坏为 O(n)，每份历史快照占 O(n) 空间。这里选择快照是为了让初学版本容易验证；不要把它误写成 O(1)。

## 典型错误

| 错误 | 修正 |
| --- | --- |
| 修改后才保存状态 | 修改前先push旧文本 |
| 空删除也压栈 | 没有实际变化就不增加历史 |
| undo用FIFO | 必须pop最近快照 |
| 只测一次撤销 | 连续撤销直到历史耗尽 |
