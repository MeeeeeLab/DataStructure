## 一个索引逐步靠近终点

反转字符串时从最后一个下标开始，每次追加当前字符并令 `index - 1`。当 `index < 0` 时没有字符可处理，递归终止：

```java
private static void appendReverse(String text, int index, StringBuilder result) {
    if (index < 0) return;
    result.append(text.charAt(index));
    appendReverse(text, index - 1, result);
}
```

`String.length()` 返回UTF-16代码单元个数，`charAt` 的合法下标是0到 `length()-1`。本练习使用普通BMP字符；若以后处理emoji等补充字符，需要按code point处理，但这不属于今日范围。

## 两个索引向中间收缩

判断回文只需比较两端字符。若 `left >= right`，说明已经比较完；若两端不同立即返回false；相同才递归到 `left+1, right-1`。空串初始为0和-1，会直接满足终止条件，因此视为回文。

## 复杂度与边界

反转与回文最多检查n个字符，时间复杂度O(n)。递归深度与n成正比，所以额外调用栈空间O(n)；反转结果还需要O(n)输出空间。null不是空串，示例明确抛出 `IllegalArgumentException`。

## 易错点

| 错误 | 后果 |
| --- | --- |
| 从length()调用charAt | 下标越界，最后合法下标是length()-1 |
| 回文只写left==right终止 | 偶数长度会让两指针交叉后继续 |
| 递归时索引不变化 | 问题不缩小，无法终止 |
| 把null当空串 | 掩盖调用契约错误 |
