## 核心原理

在 `current` 后插入 `node`，先保存 `after = current.next`，再连接：

1. `current.next = node`
2. `node.prev = current`
3. `node.next = after`
4. 若 `after != null`，令 `after.prev = node`；否则更新 `tail`

查找目标最坏 O(n)，已知节点后的连接本身 O(1)。

## 可运行示例

```java
public class DoublyLinkedInsertAfter {
    static class Node {
        int value;
        Node prev;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    private Node head;
    private Node tail;

    void addLast(int value) {
        Node node = new Node(value);
        if (tail == null) {
            head = tail = node;
        } else {
            tail.next = node;
            node.prev = tail;
            tail = node;
        }
    }

    boolean insertAfter(int target, int value) {
        Node current = head;
        while (current != null && current.value != target) current = current.next;
        if (current == null) return false;

        Node node = new Node(value);
        Node after = current.next;
        current.next = node;
        node.prev = current;
        node.next = after;
        if (after == null) {
            tail = node;
        } else {
            after.prev = node;
        }
        return true;
    }

    String forward() {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    String backward() {
        StringBuilder result = new StringBuilder();
        for (Node current = tail; current != null; current = current.prev) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        DoublyLinkedInsertAfter list = new DoublyLinkedInsertAfter();
        check(!list.insertAfter(1, 2), "empty");
        list.addLast(10);
        list.addLast(30);
        check(list.insertAfter(10, 20), "middle insert");
        check(list.insertAfter(30, 40), "tail insert");
        check(!list.insertAfter(99, 50), "missing target");
        check(list.forward().equals("10 -> 20 -> 30 -> 40"), "forward");
        check(list.backward().equals("40 -> 30 -> 20 -> 10"), "backward");
        System.out.println("middle-insert checks: OK");
    }
}
```

运行 `java DoublyLinkedInsertAfter.java`，已核对：

```text
middle-insert checks: OK
```

覆盖空链、链中插入、尾后插入、目标不存在和双向遍历。

## 易错点

- 改写 `current.next` 前没有保存后继。
- 忘记 `after.prev = node`。
- 尾后插入时忘记更新 `tail`。
- 把“找到节点后的 O(1) 连接”误说成整个按值插入 O(1)。
