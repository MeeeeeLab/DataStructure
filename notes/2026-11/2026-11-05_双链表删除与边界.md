## 核心原理

找到 `current` 后：

- 若没有前驱，令 `head = current.next`；否则 `current.prev.next = current.next`。
- 若没有后继，令 `tail = current.prev`；否则 `current.next.prev = current.prev`。

这两组判断同时覆盖中间、头、尾和单节点。按值查找最坏 O(n)，已知节点的重连 O(1)。

## 可运行示例

```java
public class DoublyLinkedDelete {
    static class Node {
        int value;
        Node prev;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    private Node head;
    private Node tail;

    void addLast(int value) {
        Node node = new Node(value);
        if (tail == null) {
            head = tail = node;
        } else {
            tail.next = node;
            node.prev = tail;
            tail = node;
        }
    }

    boolean removeFirst(int target) {
        Node current = head;
        while (current != null && current.value != target) current = current.next;
        if (current == null) return false;

        if (current.prev == null) {
            head = current.next;
        } else {
            current.prev.next = current.next;
        }
        if (current.next == null) {
            tail = current.prev;
        } else {
            current.next.prev = current.prev;
        }
        return true;
    }

    String forward() {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    String backward() {
        StringBuilder result = new StringBuilder();
        for (Node current = tail; current != null; current = current.prev) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        DoublyLinkedDelete list = new DoublyLinkedDelete();
        check(!list.removeFirst(1), "empty");
        list.addLast(10);
        list.addLast(20);
        list.addLast(30);
        check(list.removeFirst(20), "middle");
        check(list.forward().equals("10 -> 30"), "middle result");
        check(list.removeFirst(10), "head");
        check(list.removeFirst(30), "single tail");
        check(list.forward().equals("") && list.backward().equals(""), "empty again");
        check(!list.removeFirst(99), "missing");
        System.out.println("delete checks: OK");
    }
}
```

运行 `java DoublyLinkedDelete.java`，已核对：

```text
delete checks: OK
```

## 易错点

- 只改前驱的 next，忘记后继的 prev。
- 删除 head 后忘记新 head.prev 应为 null。
- 删除 tail 后忘记新 tail.next 应为 null。
- 单节点删除只更新一端，留下失效 head 或 tail。
- 未命中时仍修改链。
