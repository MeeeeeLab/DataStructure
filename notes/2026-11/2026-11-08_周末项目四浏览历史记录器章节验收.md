## 1. 双链表需要维护什么

每个节点保存 `prev` 和 `next` 两条引用。整个链表应满足：

1. 空链表时 `head`、`tail`、`current` 都是 `null`。
2. 非空时 `head.prev == null`，`tail.next == null`。
3. 若 `x.next == y`，就必须同时有 `y.prev == x`。
4. 若 `x.prev == y`，就必须同时有 `y.next == x`。
5. `current` 必须指向当前历史中的一个节点。

后退到 B 后访问 D，原来的 B→C 前进边必须断开，再连接 B→D。否则就会出现一条不符合浏览器行为的旧分支。

## 2. 可运行的 Java 周日版本

保存为 `BrowserHistoryProject.java`，在终端运行 `java BrowserHistoryProject.java`。

```java
public class BrowserHistoryProject {
    static class Node {
        String page;
        Node prev;
        Node next;
        Node(String page) { this.page = page; }
    }

    private Node head;
    private Node tail;
    private Node current;

    String currentPage() {
        return current == null ? null : current.page;
    }

    void visit(String page) {
        if (page == null || page.isBlank()) {
            throw new IllegalArgumentException("page is required");
        }
        Node node = new Node(page.strip());
        if (current == null) {
            head = tail = current = node;
            return;
        }
        current.next = null;
        tail = current;
        node.prev = current;
        current.next = node;
        current = tail = node;
    }

    String back() {
        if (current != null && current.prev != null) current = current.prev;
        return currentPage();
    }

    String forward() {
        if (current != null && current.next != null) current = current.next;
        return currentPage();
    }

    String forwardPages() {
        StringBuilder out = new StringBuilder();
        for (Node node = head; node != null; node = node.next) {
            if (!out.isEmpty()) out.append(" -> ");
            out.append(node.page);
        }
        return out.toString();
    }

    String backwardPages() {
        StringBuilder out = new StringBuilder();
        for (Node node = tail; node != null; node = node.prev) {
            if (!out.isEmpty()) out.append(" -> ");
            out.append(node.page);
        }
        return out.toString();
    }

    static void check(boolean ok, String message) {
        if (!ok) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        BrowserHistoryProject history = new BrowserHistoryProject();
        check(history.currentPage() == null, "empty current");
        check(history.back() == null && history.forward() == null, "empty movement");
        check(history.forwardPages().isEmpty() && history.backwardPages().isEmpty(), "empty traversal");

        history.visit("A");
        history.visit("B");
        history.visit("C");
        check(history.forwardPages().equals("A -> B -> C"), "forward traversal");
        check(history.backwardPages().equals("C -> B -> A"), "backward traversal");

        check(history.back().equals("B"), "back once");
        check(history.back().equals("A"), "back twice");
        check(history.back().equals("A"), "head boundary");
        check(history.forward().equals("B"), "forward once");

        history.visit("D");
        check(history.currentPage().equals("D"), "new current");
        check(history.forward().equals("D"), "tail boundary");
        check(history.forwardPages().equals("A -> B -> D"), "discard old branch");
        check(history.backwardPages().equals("D -> B -> A"), "back links after branch");

        BrowserHistoryProject single = new BrowserHistoryProject();
        single.visit("only");
        check(single.forwardPages().equals("only") && single.backwardPages().equals("only"), "single node");

        System.out.println("forward: " + history.forwardPages());
        System.out.println("backward: " + history.backwardPages());
        try {
            history.visit("  ");
        } catch (IllegalArgumentException expected) {
            System.out.println("history chapter checks: OK");
            return;
        }
        throw new AssertionError("blank page accepted");
    }
}
```

运行结果：

```text
forward: A -> B -> D
backward: D -> B -> A
history chapter checks: OK
```

## 3. 复杂度与边界

| 操作 | 时间复杂度 | 原因 |
| --- | --- | --- |
| `visit` | O(1) | 只修改当前位置附近的引用 |
| `back` / `forward` | O(1) | 只读取一个相邻节点 |
| `forwardPages` / `backwardPages` | O(n) | 必须访问每个节点 |
| 总空间 | O(n) | 每个页面对应一个节点 |

| 测试 | 预期 |
| --- | --- |
| 空历史 | 当前页为 null，前后移动不报错 |
| 单节点 | 正反向遍历都只输出 only |
| 到达最早页面再后退 | 仍停留在最早页面 |
| 到达最新页面再前进 | 仍停留在最新页面 |
| 后退后访问新页面 | 旧前进分支不可再到达 |
| 空白页面 | 抛出 IllegalArgumentException |

## 4. 章节独立实现验收

不要复制上面的代码。新建一个空文件，按以下顺序独立实现：

1. 写出 `Node(page, prev, next)`。
2. 定义 `head`、`tail`、`current`。
3. 实现 `visit`，并保证新访问会丢弃旧前进分支。
4. 实现安全的 `back` 和 `forward`。
5. 实现正向、反向遍历。
6. 自己补充空链、单节点、首尾停留和分支访问测试。

验收标准是能从空文件完成最小实现并解释引用变化；本笔记发布不代表用户已经完成验收。

## 5. 易错点

- 只改 `current.next`，却忘记设置新节点的 `prev`。
- 后退后访问新页面，忘记切断旧的 `next`。
- 空链表直接读取 `current.page`。
- 把遍历全部页面也误判成 O(1)。
- 只测 A→B→C，不测单节点和空历史。
