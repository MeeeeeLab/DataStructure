## 1. 栈是什么

栈遵循 **后进先出（LIFO）**：最后放进去的元素最先取出。可以把它想成一摞盘子：

- `push`：把元素压到栈顶。
- `pop`：移除并返回栈顶元素。
- `peek`：只查看栈顶，不移除。
- 空栈上不能正常弹出元素，必须先定义边界行为。

Java 官方建议使用 `Deque` 及其实现（如 `ArrayDeque`）作为栈，而不是旧的 `Stack` 类。本练习用 `push` 记录动作，用 `poll` 实现“空栈返回 null”的安全撤销，用 `peek` 查看最新动作。

## 2. 可运行示例

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ActionHistory {
    private final Deque<String> actions = new ArrayDeque<>();

    void record(String action) {
        if (action == null || action.isBlank()) {
            throw new IllegalArgumentException("action is required");
        }
        actions.push(action.strip());
    }

    String undo() {
        return actions.poll();
    }

    String latest() {
        return actions.peek();
    }

    int size() {
        return actions.size();
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        ActionHistory history = new ActionHistory();
        check(history.undo() == null && history.latest() == null, "empty");
        history.record("type A");
        history.record("type B");
        history.record("delete B");
        check(history.latest().equals("delete B") && history.size() == 3, "peek");
        check(history.undo().equals("delete B"), "first undo");
        check(history.undo().equals("type B"), "second undo");
        check(history.undo().equals("type A"), "third undo");
        check(history.undo() == null && history.size() == 0, "empty again");
        try {
            history.record("  ");
        } catch (IllegalArgumentException expected) {
            System.out.println("stack checks: OK");
            return;
        }
        throw new AssertionError("blank action accepted");
    }
}
```

运行 `java ActionHistory.java`，已核对空栈、三次入栈、查看栈顶、LIFO 撤销、再次变空与空白动作：

```text
stack checks: OK
```

## 3. 操作追踪

依次记录 `type A`、`type B`、`delete B` 后，栈顶是 `delete B`。连续撤销顺序为：

```text
delete B
type B
type A
```

这正是“后进先出”。`peek` 不改变数量，`pop/poll` 会使数量减一。

## 4. 复杂度与边界

`ArrayDeque` 的栈顶操作通常为 O(1)；保存 n 个动作需要 O(n) 空间。今日不分析其扩容细节，也不手写数组栈，留给后续工作日。

| 情况 | 本练习行为 |
| --- | --- |
| 空栈 `latest()` | 返回 `null` |
| 空栈 `undo()` | 返回 `null` |
| 空白动作 | 抛出 `IllegalArgumentException` |
| 查看栈顶 | 不删除元素 |
| 撤销 | 删除并返回最新动作 |
