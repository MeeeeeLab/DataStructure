## 核心理解

递归方法会直接或间接调用自身。安全递归需要两件事：

1. **终止条件**：某些输入直接返回，不再递归。
2. **缩小问题**：递归调用的参数持续靠近终止条件。

例如 `sumTo(4)`：

```text
sumTo(4)
= 4 + sumTo(3)
= 4 + 3 + sumTo(2)
= 4 + 3 + 2 + sumTo(1)
= 4 + 3 + 2 + 1 + sumTo(0)
= 10
```

`n==0`是终止条件，`n-1`保证问题逐步缩小。若遗漏终止条件或参数不变化，调用会不断加深，最终可能出现 `StackOverflowError`。

## Java 示例

```java
static int sumTo(int n) {
    if (n < 0) throw new IllegalArgumentException("n must be non-negative");
    if (n == 0) return 0;
    return n + sumTo(n - 1);
}
```

调用先一路进入到0，再从最深层开始返回。对n而言，时间复杂度O(n)，调用栈额外空间O(n)。

## 易错点与边界

| 情况 | 处理 |
| --- | --- |
| n=0 | 直接返回0，不再递归 |
| n<0 | 明确拒绝，否则n-1会远离0 |
| 递归传入n | 参数不变，无法靠近终止条件 |
| 只看最终答案 | 还要追踪进入顺序与返回顺序 |
