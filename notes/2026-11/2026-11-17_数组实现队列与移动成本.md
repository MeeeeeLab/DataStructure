# 2026-11-17｜数组实现队列与移动成本

> 队列 · Java · 建议用时 30–35 分钟 · 发布内容不表示已经完成。

## 今日目标

- 只用Java数组实现固定容量FIFO队列。
- 理解“删除队头后整体左移”为什么最坏是O(n)。
- 覆盖空队列、非法票号、满队列、单元素和耗尽边界。

## 核心理解

最直接的数组队列可以把队头固定在下标0，把队尾写在 `size`。入队只写一个槽，是O(1)；出队后为维持队头仍在0，需要把最多n-1个元素逐个左移，所以是O(n)。`peek`只读下标0，是O(1)；数组占用O(capacity)空间。这个版本故意展示移动成本，后续再用环形下标避免每次搬移。

## 可运行示例

```java
import java.util.NoSuchElementException;

public class ArrayServiceQueue {
    private final String[] data;
    private int size;

    public ArrayServiceQueue(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException("capacity must be positive");
        data = new String[capacity];
    }

    public void enqueue(String ticket) {
        if (ticket == null || ticket.isBlank()) throw new IllegalArgumentException("ticket cannot be blank");
        if (size == data.length) throw new IllegalStateException("queue is full");
        data[size++] = ticket;
    }

    public String dequeue() {
        if (size == 0) throw new NoSuchElementException("queue is empty");
        String first = data[0];
        for (int i = 1; i < size; i++) data[i - 1] = data[i];
        data[--size] = null;
        return first;
    }

    public String peek() {
        if (size == 0) throw new NoSuchElementException("queue is empty");
        return data[0];
    }

    public int size() {
        return size;
    }

    private static void expect(Class<? extends Throwable> type, Runnable action) {
        try {
            action.run();
        } catch (Throwable error) {
            if (type.isInstance(error)) return;
            throw error;
        }
        throw new AssertionError("expected " + type.getSimpleName());
    }

    public static void main(String[] args) {
        ArrayServiceQueue queue = new ArrayServiceQueue(2);
        expect(NoSuchElementException.class, queue::dequeue);
        expect(IllegalArgumentException.class, () -> queue.enqueue(" "));
        queue.enqueue("A01");
        queue.enqueue("A02");
        assert queue.size() == 2;
        assert queue.peek().equals("A01");
        expect(IllegalStateException.class, () -> queue.enqueue("A03"));
        assert queue.dequeue().equals("A01");
        assert queue.dequeue().equals("A02");
        assert queue.size() == 0;
        expect(NoSuchElementException.class, queue::peek);
        expect(IllegalArgumentException.class, () -> new ArrayServiceQueue(0));
        System.out.println("array-queue checks: OK");
    }
}
```

运行：

```bash
java -ea ArrayServiceQueue.java
```

预期输出：

```text
array-queue checks: OK
```

本次已用OpenJDK 21源码模式实际运行；正常FIFO、空队列、空白票号、满队列、耗尽和非法容量均通过。

## 复杂度

| 操作 | 时间 | 原因 |
| --- | --- | --- |
| enqueue | O(1) | 写入data[size] |
| peek | O(1) | 读取data[0] |
| dequeue | O(n) | 最坏左移n-1个元素 |
| 存储 | O(capacity) | 固定数组 |

## 易错点辨析

| 容易误解 | 正确理解 | 后果 |
| --- | --- | --- |
| 数组访问O(1)，所以出队一定O(1) | 单次访问O(1)，但左移循环执行O(n)次 | 忽略整体成本 |
| 出队后只减size | 队头若固定为0，剩余元素必须左移 | 下次返回错误元素 |
| 不清空末尾槽 | 引用会继续保留 | 不必要的对象滞留 |
| 空队列返回随意值 | 应采用稳定、明确的边界契约 | 调用者难以判断 |
