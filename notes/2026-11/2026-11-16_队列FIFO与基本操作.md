# 2026-11-16｜队列 FIFO 与基本操作

> 队列 · Java · 建议用时 30–35 分钟 · 发布内容不表示已经完成。

## 今日目标

- 区分FIFO队列与LIFO栈。
- 用Deque的尾入头出实现队列。
- 覆盖空队列、非法姓名与队列耗尽。

## 核心理解

队列按到达顺序服务：最早加入的元素最先移除。使用Deque时，offerLast把元素放到队尾，peekFirst查看队头但不删除，pollFirst移除队头；这种方法方向统一、语义清晰。

## 可运行示例

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ServiceQueue {
    private final Deque<String> people = new ArrayDeque<>();

    boolean join(String name) {
        if (name == null || name.isBlank()) return false;
        people.offerLast(name.strip());
        return true;
    }

    String serve() {
        return people.pollFirst();
    }

    String next() {
        return people.peekFirst();
    }

    int size() {
        return people.size();
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        ServiceQueue queue = new ServiceQueue();
        check(queue.serve() == null && queue.next() == null, "empty queue");
        check(!queue.join("  ") && !queue.join(null), "invalid name");
        check(queue.join("Amy") && queue.join("Bo") && queue.join("Cat"), "join");
        check(queue.next().equals("Amy") && queue.size() == 3, "peek");
        check(queue.serve().equals("Amy"), "serve Amy");
        check(queue.serve().equals("Bo") && queue.serve().equals("Cat"), "FIFO");
        check(queue.size() == 0 && queue.serve() == null, "drained queue");
        System.out.println("service-queue checks: OK");
    }
}
```

运行：

```bash
java ServiceQueue.java
```

输出：

```text
service-queue checks: OK
```

## 复杂度

ArrayDeque的大多数端点操作为摊还O(1)；保存n个排队者需要O(n)空间。

## 易错点

| 错误 | 修正 |
| --- | --- |
| 入队和出队都用同一端 | 会变成栈式LIFO。 |
| 空队列直接removeFirst | 会抛异常；本练习用pollFirst稳定返回null。 |
| peek后size减少 | peek只查看，不删除。 |
