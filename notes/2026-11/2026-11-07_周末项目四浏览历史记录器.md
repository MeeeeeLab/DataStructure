## 项目模型

每个页面节点保存 `page`、`prev`、`next`，`current` 指向当前页面：

- `visit`：在当前节点后接新页面；若曾后退，原前进链被丢弃。
- `back`：有前驱才移动，否则停在最早页面。
- `forward`：有后继才移动，否则停在最新页面。
- 空历史时三个查询操作都安全返回 `null`。

## 可运行示例

```java
public class BrowserHistoryProject {
    static class Node { String page; Node prev, next; Node(String page) { this.page = page; } }
    private Node current;

    String currentPage() { return current == null ? null : current.page; }

    void visit(String page) {
        if (page == null || page.isBlank()) throw new IllegalArgumentException("page is required");
        Node node = new Node(page.strip());
        if (current != null) { current.next = node; node.prev = current; }
        current = node;
    }

    String back() { if (current != null && current.prev != null) current = current.prev; return currentPage(); }
    String forward() { if (current != null && current.next != null) current = current.next; return currentPage(); }
    static void check(boolean ok, String message) { if (!ok) throw new AssertionError(message); }

    public static void main(String[] args) {
        BrowserHistoryProject history = new BrowserHistoryProject();
        check(history.currentPage() == null && history.back() == null && history.forward() == null, "empty");
        history.visit("A"); history.visit("B"); history.visit("C");
        check(history.back().equals("B") && history.back().equals("A") && history.back().equals("A"), "back boundary");
        check(history.forward().equals("B"), "forward");
        history.visit("D");
        check(history.currentPage().equals("D") && history.forward().equals("D"), "discard forward history");
        try { history.visit("  "); } catch (IllegalArgumentException expected) { System.out.println("history checks: OK"); return; }
        throw new AssertionError("blank page accepted");
    }
}
```

运行 `java BrowserHistoryProject.java`，已核对空历史、连续访问、首尾停留、后退后新访问清除前进历史及空白页面：

```text
history checks: OK
```

## 复杂度与边界

`visit`、`back`、`forward` 都只修改或读取相邻引用，时间 O(1)。每个页面一个节点，总空间 O(n)。删除整段前进历史在本最小实现中通过断开 `current.next` 完成，失去引用的节点交由垃圾回收。

典型错误：只写 `next` 不写新节点的 `prev`；后退后访问新页面却保留旧前进链；空历史解引用；到达边界后继续移动成 `null`。
