## 1. 为什么同时保存 head 与 tail

昨天的尾插为了找到末尾需要遍历，成本是 O(n)。今天让双链表对象同时保存：

- `head`：第一个节点；
- `tail`：最后一个节点。

因此头插直接改 `head`，尾插直接改 `tail`，两者都是 O(1)。代价是每次修改都必须保持首尾和双向引用一致。

## 2. 两种插入

非空头插：

1. `node.next = head`
2. `head.prev = node`
3. `head = node`

非空尾插：

1. `tail.next = node`
2. `node.prev = tail`
3. `tail = node`

空链是共同边界：新节点既是 `head`，也是 `tail`。

## 3. 可运行 Java 示例

```java
public class DoublyLinkedEnds {
    static class Node {
        int value;
        Node prev;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    private Node head;
    private Node tail;

    void addFirst(int value) {
        Node node = new Node(value);
        if (head == null) {
            head = tail = node;
            return;
        }
        node.next = head;
        head.prev = node;
        head = node;
    }

    void addLast(int value) {
        Node node = new Node(value);
        if (tail == null) {
            head = tail = node;
            return;
        }
        tail.next = node;
        node.prev = tail;
        tail = node;
    }

    String forward() {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    String backward() {
        StringBuilder result = new StringBuilder();
        for (Node current = tail; current != null; current = current.prev) {
            if (!result.isEmpty()) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    boolean linksAreValid() {
        if ((head == null) != (tail == null)) return false;
        if (head != null && head.prev != null) return false;
        if (tail != null && tail.next != null) return false;
        for (Node current = head; current != null; current = current.next) {
            if (current.next != null && current.next.prev != current) return false;
        }
        return true;
    }

    static void check(boolean condition, String message) {
        if (!condition) throw new AssertionError(message);
    }

    public static void main(String[] args) {
        DoublyLinkedEnds list = new DoublyLinkedEnds();
        check(list.forward().equals("") && list.backward().equals(""), "empty");
        check(list.linksAreValid(), "empty links");

        list.addFirst(20);
        check(list.forward().equals("20") && list.backward().equals("20"), "single");
        list.addFirst(10);
        list.addLast(30);
        check(list.forward().equals("10 -> 20 -> 30"), "forward");
        check(list.backward().equals("30 -> 20 -> 10"), "backward");
        check(list.linksAreValid(), "links");

        System.out.println("end-insert checks: OK");
    }
}
```

运行：

```bash
java DoublyLinkedEnds.java
```

已核对输出：

```text
end-insert checks: OK
```

自检覆盖空链、单节点、混合头尾插、正反向遍历和连接一致性。

## 4. 复杂度

| 操作 | 时间 | 原因 |
| --- | ---: | --- |
| `addFirst` | O(1) | 直接使用 `head` |
| `addLast` | O(1) | 直接使用 `tail` |
| 正向/反向遍历 | O(n) | 每个节点访问一次 |
| 存储 | O(n) | 每个节点保存值和两个引用 |

## 5. 易错点

- 空链只设置 `head`，忘记同步 `tail`。
- 头插只写 `node.next`，忘记原头的 `prev`。
- 尾插只写 `node.prev`，忘记原尾的 `next`。
- 插入后让 `head.prev` 或 `tail.next` 非空。
- 今天提前加入删除逻辑，混淆当前不变量。
