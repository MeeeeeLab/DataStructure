## 今日目标

- 用半开区间`[from, to)`描述数组子问题。
- 让`from`每次加1并在`from == to`时终止。
- 验证空区间、负数、空数组、null与越界索引。

## 把区间缩小一个元素

对于`[from, to)`，当前元素是`values[from]`，剩余问题是`[from+1, to)`：

```java
if (from == to) {
    return 0L;
}
return values[from] + sumRange(values, from + 1, to);
```

半开区间的好处是长度直接等于`to-from`，空区间自然写成`from==to`。数组长度为n时，合法端点允许`to==n`，但真正访问的最大下标仍是`n-1`。

## 先检查契约再递归

示例要求`0 <= from <= to <= values.length`。null不是空数组，单独抛`IllegalArgumentException`；错误端点抛`IndexOutOfBoundsException`。公开方法只在最外层检查一次会更高效，但今天把检查保留在单一方法中以突出完整契约，复杂度结论仍按处理区间长度分析。

## 复杂度

区间长度记为k。每层处理一个元素，因此时间复杂度O(k)，递归调用栈空间O(k)。空区间k=0直接返回0。返回`long`可扩大求和范围，但极大数组或极端数值仍可能溢出；今日不延伸到大整数。

## 易错点

| 错误 | 后果 |
| --- | --- |
| 终止条件写成from > to | 空区间仍会访问values[to] |
| 访问values[to] | to是排除端，不是合法区间元素 |
| 递归时from不增加 | 子问题不缩小，无法终止 |
| 把to==length判为非法 | 半开区间允许排除端等于length |
