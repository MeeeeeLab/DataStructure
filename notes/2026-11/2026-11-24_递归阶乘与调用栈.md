## 从求和到阶乘

昨天的求和是`n + sumTo(n-1)`；阶乘把组合方式换成乘法：

```java
static long factorial(int n) {
    if (n < 0 || n > 20) {
        throw new IllegalArgumentException("n must be from 0 to 20");
    }
    if (n == 0) return 1;
    return n * factorial(n - 1);
}
```

`0! = 1`是终止条件。计算`factorial(4)`时，调用按4、3、2、1、0深入；到0返回后，结果按1、1、2、6、24形成。每层调用都要保存自己的参数和返回位置，这些信息位于调用栈中。

## 复杂度与边界

递归深度为n+1，所以时间复杂度O(n)，额外调用栈空间O(n)。Java的`long`能保存20!，但21!会溢出，因此示例在递归前限制0到20。输入为负数时，n-1会远离0，也必须拒绝。

## 易错点

| 错误 | 后果 |
| --- | --- |
| n==0时返回0 | 后续乘法全部变成0 |
| 递归调用factorial(n) | 参数不缩小，无法终止 |
| 不检查负数 | 递归继续远离0 |
| 忽略21!边界 | long发生溢出，结果失真 |
