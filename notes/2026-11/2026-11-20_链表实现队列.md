# 2026-11-20｜链表实现队列

> 队列 · Java · 建议用时 30–35 分钟 · 发布内容不表示已经完成。

## 今日目标

- 用单链表的head和tail实现FIFO队列。
- 保持enqueue、dequeue和peek的最坏O(1)。
- 正确处理空队列、单元素清空和清空后重新入队。

## 核心理解

链表队列把最早进入的节点放在head，最新节点放在tail。入队时把新节点接到 `tail.next` 并更新tail；出队时把head移动到 `head.next`。两种操作都不需要遍历。最容易遗漏的是删除最后一个节点：此时新head为null，tail也必须同步设为null，才能保持空队列不变量。

## 可运行示例

```java
import java.util.NoSuchElementException;

public class LinkedServiceQueue {
    private static class Node {
        String ticket;
        Node next;

        Node(String ticket) {
            this.ticket = ticket;
        }
    }

    private Node head;
    private Node tail;
    private int size;

    public void enqueue(String ticket) {
        if (ticket == null || ticket.isBlank()) {
            throw new IllegalArgumentException("ticket cannot be blank");
        }
        Node added = new Node(ticket);
        if (tail == null) {
            head = added;
        } else {
            tail.next = added;
        }
        tail = added;
        size++;
    }

    public String dequeue() {
        if (head == null) {
            throw new NoSuchElementException("queue is empty");
        }
        String ticket = head.ticket;
        head = head.next;
        size--;
        if (head == null) {
            tail = null;
        }
        return ticket;
    }

    public String peek() {
        if (head == null) {
            throw new NoSuchElementException("queue is empty");
        }
        return head.ticket;
    }

    public int size() {
        return size;
    }

    private static void expect(Class<? extends Throwable> type, Runnable action) {
        try {
            action.run();
        } catch (Throwable error) {
            if (type.isInstance(error)) return;
            throw error;
        }
        throw new AssertionError("expected " + type.getSimpleName());
    }

    public static void main(String[] args) {
        LinkedServiceQueue queue = new LinkedServiceQueue();
        expect(NoSuchElementException.class, queue::dequeue);
        expect(IllegalArgumentException.class, () -> queue.enqueue(" "));
        queue.enqueue("A");
        assert queue.peek().equals("A");
        assert queue.dequeue().equals("A");
        assert queue.size() == 0;

        queue.enqueue("B");
        queue.enqueue("C");
        queue.enqueue("D");
        assert queue.dequeue().equals("B");
        assert queue.dequeue().equals("C");
        assert queue.dequeue().equals("D");
        expect(NoSuchElementException.class, queue::peek);
        System.out.println("linked-queue checks: OK");
    }
}
```

运行：

```bash
java -ea LinkedServiceQueue.java
```

预期输出：

```text
linked-queue checks: OK
```

已用OpenJDK源码模式并开启断言实际运行；空队列、空白票号、单元素清空、重新入队和三元素FIFO均通过。

## 复杂度

| 操作 | 时间 | 原因 |
| --- | --- | --- |
| enqueue | O(1) | 直接通过tail连接新节点 |
| dequeue | O(1) | 直接移动head |
| peek | O(1) | 读取head.ticket |
| 存储 | O(n) | 每个元素一个节点 |

## 易错点辨析

| 容易误解 | 正确理解 | 后果 |
| --- | --- | --- |
| 只保存head也能快速入队 | 没有tail就要遍历到末尾 | 入队退化为O(n) |
| 删除最后节点只改head | 空队列时tail也必须为null | 后续入队连接到旧节点 |
| tail是下一个空位置 | 链表tail指向最后一个实际节点 | 指针更新混乱 |
| 节点删除后size不用改 | size必须与可达节点数一致 | 状态不变量破坏 |
