## 1. 从单向到双向

单链表节点只有 `next`；双链表节点再增加 `prev`。对相邻节点 `x` 与 `y`，若 `x.next == y`，就必须同时满足 `y.prev == x`。边界通常是：

- 头节点的 `prev == null`
- 尾节点的 `next == null`

这两个方向必须成对维护，否则正向遍历可能正常，反向遍历却会断裂或走错。

## 2. 最小可运行示例

```java
public class DoublyLinkedListBasics {
    static class Node {
        int value;
        Node prev;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    static Node append(Node head, int value) {
        Node node = new Node(value);
        if (head == null) {
            return node;
        }
        Node tail = last(head);
        tail.next = node;
        node.prev = tail;
        return head;
    }

    static Node last(Node head) {
        if (head == null) {
            return null;
        }
        Node current = head;
        while (current.next != null) {
            current = current.next;
        }
        return current;
    }

    static String forward(Node head) {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (!result.isEmpty()) {
                result.append(" -> ");
            }
            result.append(current.value);
        }
        return result.toString();
    }

    static String backward(Node tail) {
        StringBuilder result = new StringBuilder();
        for (Node current = tail; current != null; current = current.prev) {
            if (!result.isEmpty()) {
                result.append(" -> ");
            }
            result.append(current.value);
        }
        return result.toString();
    }

    static boolean linksAreSymmetric(Node head) {
        for (Node current = head; current != null; current = current.next) {
            if (current.next != null && current.next.prev != current) {
                return false;
            }
        }
        return true;
    }

    static void check(boolean condition, String message) {
        if (!condition) {
            throw new AssertionError(message);
        }
    }

    public static void main(String[] args) {
        check(forward(null).equals(""), "empty forward traversal");
        check(backward(null).equals(""), "empty backward traversal");

        Node head = null;
        head = append(head, 10);
        head = append(head, 20);
        head = append(head, 30);
        check(forward(head).equals("10 -> 20 -> 30"), "forward traversal");
        check(backward(last(head)).equals("30 -> 20 -> 10"), "backward traversal");
        check(linksAreSymmetric(head), "prev and next must agree");

        Node one = append(null, 7);
        check(forward(one).equals("7"), "single-node forward traversal");
        check(backward(last(one)).equals("7"), "single-node backward traversal");

        System.out.println("doubly-linked checks: OK");
    }
}
```

运行：

```bash
java DoublyLinkedListBasics.java
```

已核对输出：

```text
doubly-linked checks: OK
```

示例覆盖空链、单节点、三个节点、正向遍历、反向遍历和相邻连接一致性。

## 3. 复杂度

- 当前 `append` 没有保存 `tail`，要先找末尾，因此是 O(n)。
- 正向或反向遍历都是 O(n)。
- 若已经拿到两个相邻位置，设置一对 `next/prev` 是 O(1)。
- n 个节点额外保存引用，空间仍为 O(n)。

## 4. 易错点

1. 只写 `tail.next = node`，忘记 `node.prev = tail`。
2. 反向遍历从 `head` 开始，而不是从 `tail` 开始。
3. 空链调用 `last(null)` 后继续解引用。
4. 今天提前加入删除、哨兵节点或复杂容器，偏离短课范围。
