## 核心比较

单链表节点只有 `next`，结构小、正向遍历直接；双链表节点多一个 `prev`，能反向遍历。已知双链表中的非空节点时，可直接连接前后邻居；单链表若没有前驱引用，通常要从头查找前驱。

两者按值查找都最坏 O(n)。已知节点的双链表中间删除重连 O(1)，但必须同时维护 `prev` 与 `next`。

## 可运行示例

```java
public class LinkedListComparison {
    static class SNode { int value; SNode next; SNode(int value) { this.value = value; } }
    static class DNode { int value; DNode prev, next; DNode(int value) { this.value = value; } }

    static String singlyForward(SNode head) {
        StringBuilder out = new StringBuilder();
        for (SNode n = head; n != null; n = n.next) { if (!out.isEmpty()) out.append(" -> "); out.append(n.value); }
        return out.toString();
    }

    static String doublyForward(DNode head) {
        StringBuilder out = new StringBuilder();
        for (DNode n = head; n != null; n = n.next) { if (!out.isEmpty()) out.append(" -> "); out.append(n.value); }
        return out.toString();
    }

    static String doublyBackward(DNode tail) {
        StringBuilder out = new StringBuilder();
        for (DNode n = tail; n != null; n = n.prev) { if (!out.isEmpty()) out.append(" -> "); out.append(n.value); }
        return out.toString();
    }

    static void unlinkKnown(DNode node) {
        if (node.prev != null) node.prev.next = node.next;
        if (node.next != null) node.next.prev = node.prev;
    }

    static void check(boolean ok, String message) { if (!ok) throw new AssertionError(message); }

    public static void main(String[] args) {
        check(singlyForward(null).equals("") && doublyForward(null).equals(""), "empty");
        SNode s10 = new SNode(10), s20 = new SNode(20), s30 = new SNode(30);
        s10.next = s20; s20.next = s30;
        DNode d10 = new DNode(10), d20 = new DNode(20), d30 = new DNode(30);
        d10.next = d20; d20.prev = d10; d20.next = d30; d30.prev = d20;
        check(singlyForward(s10).equals("10 -> 20 -> 30"), "single forward");
        check(doublyForward(d10).equals("10 -> 20 -> 30"), "double forward");
        check(doublyBackward(d30).equals("30 -> 20 -> 10"), "double backward");
        unlinkKnown(d20);
        check(doublyForward(d10).equals("10 -> 30") && doublyBackward(d30).equals("30 -> 10"), "unlink");
        System.out.println("comparison checks: OK");
    }
}
```

运行 `java LinkedListComparison.java`，已核对空链、正向/反向遍历和已知中间节点删除：

```text
comparison checks: OK
```

## 易错点与边界

| 情况 | 单链表 | 双链表 |
| --- | --- | --- |
| 反向遍历 | 无 `prev`，不能直接进行 | 从尾沿 `prev` |
| 按值查找 | O(n) | O(n) |
| 已知中间节点删除 | 仍需前驱引用 | 两侧重连 O(1) |
| 空链遍历 | 空字符串 | 正反向均空 |
| 维护成本 | 少一条引用 | 每次修改需检查两个方向 |
