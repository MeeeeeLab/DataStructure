## 可运行项目

```java
public class StudentListProject {
    static class Node {
        String id;
        String name;
        Node next;

        Node(String id, String name) {
            this.id = id;
            this.name = name;
        }
    }

    private Node head;

    boolean addLast(String id, String name) {
        if (id == null || name == null || id.isBlank() || name.isBlank()) {
            throw new IllegalArgumentException("id and name are required");
        }
        Node node = new Node(id, name);
        if (head == null) {
            head = node;
            return true;
        }
        Node current = head;
        while (true) {
            if (current.id.equals(id)) return false;
            if (current.next == null) break;
            current = current.next;
        }
        current.next = node;
        return true;
    }

    String findName(String id) {
        for (Node current = head; current != null; current = current.next) {
            if (current.id.equals(id)) return current.name;
        }
        return null;
    }

    boolean remove(String id) {
        if (head == null) return false;
        if (head.id.equals(id)) {
            head = head.next;
            return true;
        }
        Node current = head;
        while (current.next != null && !current.next.id.equals(id)) {
            current = current.next;
        }
        if (current.next == null) return false;
        current.next = current.next.next;
        return true;
    }

    String display() {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (result.length() > 0) result.append(" -> ");
            result.append(current.id).append(":").append(current.name);
        }
        return result.toString();
    }

    public static void main(String[] args) {
        StudentListProject list = new StudentListProject();
        if (!list.display().equals("")) throw new AssertionError("empty");
        if (!list.addLast("S01", "Amy")) throw new AssertionError("first");
        if (!list.addLast("S02", "Bo")) throw new AssertionError("second");
        if (list.addLast("S01", "Again")) throw new AssertionError("duplicate");
        if (!"Bo".equals(list.findName("S02"))) throw new AssertionError("find");
        if (list.findName("S99") != null) throw new AssertionError("missing");
        if (!list.display().equals("S01:Amy -> S02:Bo")) throw new AssertionError("display");
        if (!list.remove("S01")) throw new AssertionError("remove head");
        if (!list.remove("S02")) throw new AssertionError("remove single");
        if (list.remove("S99") || !list.display().equals("")) {
            throw new AssertionError("empty remove");
        }
        System.out.println("student-list checks: OK");
    }
}
```

运行 `java StudentListProject.java`。本次核对空链、首次/连续加入、重复学号、命中/未命中查找、删除 head、删除单节点和空链删除，输出：

```text
student-list checks: OK
```

## 核心引用变化

- 空链加入：`head = node`。
- 非空尾插：找到 `current.next == null`，再连接新节点。
- 删除 head：`head = head.next`。
- 删除其他节点：让前驱的 `next` 跨过目标。
- 展示：从 head 开始，每次走向 `current.next`。

Princeton 用 `Node + next` 解释链表构建、头插头删、尾插和遍历；Java 官方 `LinkedList` 也区分首尾加入、查找和删除第一次出现。这里手写结构用于理解引用，不用库类替代。

## 复杂度

无 tail 引用时，加入、查找、删除、展示最坏都是 O(n)；空链首次加入是 O(1)。额外只使用少量引用，除输出字符串外为 O(1) 空间。

## 易错点

- 空链尾插仍进入遍历。
- 检查重复时漏掉 head 或最后一个节点。
- 删除 head 后继续用旧入口。
- 未命中时访问 `current.next.next`。
- 周日新建另一个项目 ID。
