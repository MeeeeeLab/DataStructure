## 章节验收代码

```java
import java.util.Arrays;

public class TextGradeStatsAcceptance {
    static int[] scoreSummary(int[] scores, int size) {
        if (size < 0 || size > scores.length) throw new IllegalArgumentException("size");
        if (size == 0) return new int[] {0, 0, 0, 0};
        int sum = 0, min = scores[0], max = scores[0];
        for (int i = 0; i < size; i++) {
            sum += scores[i];
            if (scores[i] < min) min = scores[i];
            if (scores[i] > max) max = scores[i];
        }
        return new int[] {size, sum, min, max};
    }

    static int[] textSummary(String text) {
        int letters = 0, digits = 0, spaces = 0, others = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isLetter(ch)) letters++;
            else if (Character.isDigit(ch)) digits++;
            else if (Character.isWhitespace(ch)) spaces++;
            else others++;
        }
        return new int[] {letters, digits, spaces, others};
    }

    static String report(int[] scores, int size, String text) {
        return "scores=" + Arrays.toString(scoreSummary(scores, size))
                + ", text=" + Arrays.toString(textSummary(text));
    }

    static void check(Object actual, Object expected) {
        if (!actual.equals(expected)) throw new AssertionError(actual);
    }

    public static void main(String[] args) {
        check(report(new int[] {70, 95, 70}, 3, "Ab 2!中"),
              "scores=[3, 235, 70, 95], text=[3, 1, 1, 1]");
        check(report(new int[] {}, 0, ""),
              "scores=[0, 0, 0, 0], text=[0, 0, 0, 0]");
        boolean rejected = false;
        try { scoreSummary(new int[] {80}, 2); }
        catch (IllegalArgumentException expected) { rejected = true; }
        if (!rejected) throw new AssertionError("invalid size accepted");
        System.out.println("chapter acceptance: OK");
    }
}
```

运行：`java TextGradeStatsAcceptance.java`。本次已核对正常组合报告、空数组与空字符串、非法有效长度，输出 `chapter acceptance: OK`。

## 验收解释

- 成绩摘要只访问 `[0, size)`，空区间先返回，非法模型明确拒绝。
- 文本分类使用互斥 `else if`，每个 `char` 只进入一类。
- 两个 O(n) 扫描先后执行仍是 O(n)，不是 O(n²)。
- `report` 只组合结果，不复制核心统计逻辑。
