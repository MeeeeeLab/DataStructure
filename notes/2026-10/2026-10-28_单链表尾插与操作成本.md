## 今天的新知识

只有 `head` 时，尾插必须先找到最后一个节点：空链表直接返回新节点；非空链表从 head 走到 `current.next == null`，再连接新节点。因此本实现尾插最坏 O(n)。维护额外 `tail` 引用可以把尾插降为 O(1)，但今天先不增加状态与同步负担。

```java
public class LinkedListAppendCost {
    static class Node {
        int value;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    static Node append(Node head, int value) {
        Node added = new Node(value);
        if (head == null) return added;
        Node current = head;
        while (current.next != null) current = current.next;
        current.next = added;
        return head;
    }

    static String traverse(Node head) {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (result.length() > 0) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    public static void main(String[] args) {
        Node head = append(null, 10);
        if (!traverse(head).equals("10")) throw new AssertionError("empty append");
        head = append(head, 20);
        head = append(head, 30);
        if (!traverse(head).equals("10 -> 20 -> 30")) throw new AssertionError("append order");
        System.out.println("append checks: OK");
    }
}
```

运行：`java LinkedListAppendCost.java`。本次已核对空链表尾插、单节点与连续尾插顺序，输出 `append checks: OK`。

## 与头插比较

| 操作 | 只有 head 时 | 原因 |
| --- | --- | --- |
| 头插 | O(1) | 直接连接旧 head |
| 尾插 | O(n) | 需要找到末节点 |
| 遍历 | O(n) | 每个节点访问一次 |

Java 官方 `LinkedList` 是双链表，并不是今天手写的单链表；它用于核对链式集合的首尾语义，不应把其内部实现直接当作我们的代码。

## 易错点

- 空链表仍访问 `current.next`。
- 尾插后错误返回新节点，导致调用者丢失原 head。
- 循环到 `current == null` 才连接，已经没有节点可修改。
- 为了 O(1) 尾插贸然添加 tail，却忘记在所有修改中同步它。
