## 独立实现契约

- `prepend`：头插，O(1)。
- `append`：无 tail 引用时尾插，最坏 O(n)。
- `contains`：顺序查找，最坏 O(n)。
- `deleteFirst`：删除第一次出现的目标，最坏 O(n)。
- `traverse`：空链输出空字符串，其余用 ` -> ` 连接。
- 所有操作都要处理空链、单节点、头尾位置和未命中。

## 可运行综合程序

```java
public class SinglyLinkedListCheck {
    static class Node {
        int value;
        Node next;

        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    static Node prepend(Node head, int value) {
        return new Node(value, head);
    }

    static Node append(Node head, int value) {
        Node node = new Node(value, null);
        if (head == null) return node;
        Node current = head;
        while (current.next != null) current = current.next;
        current.next = node;
        return head;
    }

    static boolean contains(Node head, int target) {
        for (Node current = head; current != null; current = current.next) {
            if (current.value == target) return true;
        }
        return false;
    }

    static Node deleteFirst(Node head, int target) {
        if (head == null) return null;
        if (head.value == target) return head.next;
        Node current = head;
        while (current.next != null && current.next.value != target) {
            current = current.next;
        }
        if (current.next != null) current.next = current.next.next;
        return head;
    }

    static String traverse(Node head) {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (result.length() > 0) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    public static void main(String[] args) {
        Node head = null;
        if (!traverse(head).equals("")) throw new AssertionError("empty");
        head = append(head, 20);
        head = prepend(head, 10);
        head = append(head, 30);
        if (!traverse(head).equals("10 -> 20 -> 30")) throw new AssertionError("insert");
        if (!contains(head, 20) || contains(head, 99)) throw new AssertionError("find");
        head = deleteFirst(head, 10);
        head = deleteFirst(head, 30);
        head = deleteFirst(head, 99);
        if (!traverse(head).equals("20")) throw new AssertionError("delete");
        head = deleteFirst(head, 20);
        if (head != null) throw new AssertionError("single");
        System.out.println("linked-list checks: OK");
    }
}
```

运行：

```bash
java SinglyLinkedListCheck.java
```

本次正常与边界检查输出：

```text
linked-list checks: OK
```

Princeton 的链表讲解以节点和 `next` 建立链，并展示头插、头删、尾插与遍历。Java 官方 `LinkedList` 也把 `addFirst`、`addLast` 和删除第一次出现定义为不同操作；今天手写最小链表是为了理解引用变化，不用库类代替练习。

## 复杂度复盘

| 操作 | 时间 | 原因 |
| --- | ---: | --- |
| 头插 | O(1) | 只改一个入口引用 |
| 无 tail 的尾插 | O(n) | 先走到末尾 |
| 查找 | O(n) | 最坏扫描整条链 |
| 按值删除第一次出现 | O(n) | 需要寻找目标或前驱 |
| 遍历 | O(n) | 每个节点访问一次 |

连续执行一次 O(n) 查找和一次 O(n) 删除是 O(n)+O(n)=O(n)，不是 O(n²)；只有把完整扫描嵌套在完整扫描内才会相乘。

## 易错点

- 空链时直接访问 `head.value`。
- 尾插空链后忘记接收返回的新 head。
- 删除 head 后仍使用旧 head。
- 目标不存在时继续访问 `current.next.next`。
- 把两个先后执行的线性操作误判为平方复杂度。
