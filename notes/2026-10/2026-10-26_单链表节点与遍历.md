## 新知识边界

今天只学习三个词：`Node`、`head`、遍历。暂不做按位置插入、删除、双链表或 Java 库 `LinkedList` 的复杂操作。

`Node` 保存一个值和指向下一个节点的引用 `next`。`head` 是第一个节点的引用；空链表用 `head == null` 表示。遍历时使用临时引用 `current`，不断执行 `current = current.next`，直到 `null`。

```java
public class SinglyLinkedListIntro {
    static class Node {
        int value;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    static String traverse(Node head) {
        StringBuilder result = new StringBuilder();
        Node current = head;
        while (current != null) {
            if (result.length() > 0) result.append(" -> ");
            result.append(current.value);
            current = current.next;
        }
        return result.toString();
    }

    public static void main(String[] args) {
        if (!traverse(null).equals("")) throw new AssertionError("empty");
        Node first = new Node(10);
        if (!traverse(first).equals("10")) throw new AssertionError("single");
        first.next = new Node(20);
        first.next.next = new Node(30);
        if (!traverse(first).equals("10 -> 20 -> 30")) throw new AssertionError("chain");
        System.out.println("linked-list checks: OK");
    }
}
```

运行：`java SinglyLinkedListIntro.java`。本次已核对空链表、单节点和三节点链，输出 `linked-list checks: OK`。

## 关键图景

`head -> 10 -> 20 -> 30 -> null`。变量 `current` 沿箭头移动；它的移动不会改变 `head`。若误写 `head = head.next`，则会丢失调用方保存首节点的入口。

## 复杂度

遍历 n 个节点时间 O(n)，额外使用一个 `current` 引用和一个输出构造器。访问“第 i 个节点”必须从 head 逐步走，不能像数组那样直接按下标跳转。Java 官方 `LinkedList` 文档也说明索引操作需要从较近的一端遍历；今天我们手写的是更简单的单链表节点。

## 易错点

- 忘记 `current = current.next`，循环永不结束。
- 遍历条件写成 `current.next != null`，漏掉最后一个节点且空链表会报错。
- 用 `head` 本身移动，导致首节点引用丢失。
- 把节点对象、节点中的值、整个链表混为一谈。
