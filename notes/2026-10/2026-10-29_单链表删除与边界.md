## 今日新知识

删除第一次出现的目标，需要分别处理：空链表、删除 head、删除中间/末尾、目标不存在。删除 head 时新的入口是 `head.next`；其他位置要找到目标的前驱，让 `previous.next` 跨过目标节点。

```java
public class LinkedListDeleteFirst {
    static class Node {
        int value;
        Node next;

        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    static Node deleteFirst(Node head, int target) {
        if (head == null) return null;
        if (head.value == target) return head.next;
        Node current = head;
        while (current.next != null && current.next.value != target) {
            current = current.next;
        }
        if (current.next != null) current.next = current.next.next;
        return head;
    }

    static String traverse(Node head) {
        StringBuilder result = new StringBuilder();
        for (Node current = head; current != null; current = current.next) {
            if (result.length() > 0) result.append(" -> ");
            result.append(current.value);
        }
        return result.toString();
    }

    public static void main(String[] args) {
        if (deleteFirst(null, 1) != null) throw new AssertionError("empty");
        Node head = new Node(10, new Node(20, new Node(30, null)));
        head = deleteFirst(head, 10);
        if (!traverse(head).equals("20 -> 30")) throw new AssertionError("head");
        head = deleteFirst(head, 30);
        if (!traverse(head).equals("20")) throw new AssertionError("tail");
        head = deleteFirst(head, 99);
        if (!traverse(head).equals("20")) throw new AssertionError("missing");
        head = deleteFirst(head, 20);
        if (head != null) throw new AssertionError("single");
        System.out.println("delete checks: OK");
    }
}
```

运行：`java LinkedListDeleteFirst.java`。本次已核对空链表、删除头/尾/单节点及目标不存在，输出 `delete checks: OK`。

## 为什么观察 current.next

若目标不是 head，我们需要修改“前一个节点”的 next，所以循环保持 `current` 指向前驱，并检查 `current.next.value`。找到后执行 `current.next = current.next.next`。Java 官方 `LinkedList.remove(Object)` 同样定义为删除第一次出现；这里是手写单链表练习，不使用库类代替。

## 复杂度

删除 head 是 O(1)；一般按值删除最坏要遍历 n 个节点，因此 O(n)。只改引用，不需要移动其余元素。

## 易错点

- 空链表直接访问 `head.value`。
- 删除 head 后仍返回旧 head。
- 循环只检查 current，找到目标却没有前驱可改。
- 目标不存在时访问 `current.next.next`。
- 删除所有重复值，而契约只要求第一次出现。
