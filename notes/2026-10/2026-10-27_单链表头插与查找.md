## 今天的新知识

头插只做三件事：创建新节点、让其 `next` 指向旧 `head`、返回新节点作为新 `head`。这不需要遍历，所以时间 O(1)。查找仍从 `head` 沿 `next` 逐个比较，最坏 O(n)。

```java
public class LinkedListFrontSearch {
    static class Node {
        int value;
        Node next;

        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    static Node pushFront(Node head, int value) {
        return new Node(value, head);
    }

    static boolean contains(Node head, int target) {
        for (Node current = head; current != null; current = current.next) {
            if (current.value == target) return true;
        }
        return false;
    }

    public static void main(String[] args) {
        Node head = null;
        if (contains(head, 10)) throw new AssertionError("empty");
        head = pushFront(head, 10);
        head = pushFront(head, 20);
        if (head.value != 20 || head.next.value != 10) throw new AssertionError("links");
        if (!contains(head, 10) || contains(head, 99)) throw new AssertionError("search");
        System.out.println("front/search checks: OK");
    }
}
```

运行：`java LinkedListFrontSearch.java`。本次已核对空链表查找、两次头插、命中与未命中，输出 `front/search checks: OK`。

## 核心图景

旧链：`10 -> null`。执行 `head = pushFront(head, 20)` 后：`20 -> 10 -> null`。必须接住返回的新 `head`；若只调用函数而不赋值，外部入口仍指向旧首节点。

## 易错点

- 新节点的 `next` 没指向旧 head，导致旧链丢失。
- 头插后忘记更新 head。
- 查找条件写成 `current.next != null`，漏掉最后节点。
- 用 `==` 比较对象内容；今天节点保存 int，所以比较 `value` 合法。
